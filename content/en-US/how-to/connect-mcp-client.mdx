# Connect an MCP client

You can connect an AI assistant, such as Claude Desktop or Claude Code, to
Alkemio. The assistant can then read and work with your Alkemio content when
you ask it to. To set this up, you need a personal key from Alkemio, which you
then add to your assistant. This page explains both steps.

## What MCP is

MCP (Model Context Protocol) is a common standard that lets AI assistants
connect to other services. Alkemio supports MCP, so any assistant that
supports it can work with Alkemio in the same way.

The assistant connects with a personal key that you create in Alkemio. This
key doesn't give the assistant an account of its own: everything it does
happens **as you**. It therefore has exactly the same rights as you, and never
more. It can only see the spaces and content you can see, and only change what
you are allowed to change yourself.

When you create a key, you also choose what the assistant may do with it:

- **Read** allows the assistant to open and read spaces, posts and whiteboards
  that you have access to.
- **Tools** allows the assistant to use Alkemio's tools on your behalf: for
  example searching across your spaces, summarising recent activity, and
  creating or editing whiteboards.

Most assistants need **Tools** to be useful, because searching also counts as
a tool. Keep in mind that **Tools** can't be limited further: a key with
**Tools** allows searching as well as making changes, such as editing a
whiteboard. The assistant can still only make changes where you could make
them yourself.

You can switch a key off at any time, and you can have up to 10 active keys.

## Step 1: Create a key in Alkemio

1. Click your profile picture in the top right corner and choose
   **My Account**.
2. Open the **Security** tab.
3. Under **MCP API Keys**, click **Create API key**.
4. Give the key a name that tells you where it is used, such as
   "Claude Desktop".
5. Under **Operations**, select **Read**, **Tools**, or both (see
   [What MCP is](#what-mcp-is)). If you want the key to stop working
   automatically, you can also set an expiry date.
6. Click **Create key**.
7. Your new key is shown once, immediately after it is created. Click
   **Copy** and store the key somewhere safe until Step 2, for example in a
   password manager. Alkemio can't show the key again. If you lose it, switch
   it off and create a new one.
8. Under **Connection recipe**, the same window shows the web address your
   assistant needs, next to **Endpoint**. In most cases this is
   `https://alkem.io/rest/mcp`. Write it down if yours is different, then
   click **Done**.

The key starts with `mcp_`. This is part of the key, so always paste it
exactly as you copied it.

## Step 2: Connect your AI assistant

Choose the section below that matches the assistant you use. Each section
has every step you need, even if you haven't done this before.

- **Claude Desktop**, the Claude app on your computer: see
  [Claude Desktop](#claude-desktop).
- **Claude Code**, which you use by typing in a terminal window: see
  [Claude Code](#claude-code).
- **Claude Desktop with an Alkemio address that only works inside your
  organisation's network**, such as a test version on your own computer: see
  [Claude Desktop on your own network](#claude-desktop-on-your-own-network).
- **Another assistant**: see [Other AI assistants](#other-ai-assistants).

### Claude Desktop

1. In Claude Desktop, go to **Settings → Connectors → Add custom connector**.
2. For **Name**, type `Alkemio`.
3. For **Remote MCP server URL**, type the **Endpoint** address from Step 1,
   usually `https://alkem.io/rest/mcp`.
4. Under **Authentication**, choose **None**. This is the correct option for
   services that use a key, such as Alkemio.
5. Click **+ Add header**. For **Key**, type `Authorization`. For **Value**,
   type the word `Bearer`, a space, and then paste your key, so it looks like
   `Bearer mcp_...`.
6. Click **Add**.

Alkemio now appears in Claude Desktop's list of connectors, and you can ask
Claude about your Alkemio spaces.

### Claude Code

You add Alkemio to Claude Code by pasting one command into a terminal: the
window where you type commands to your computer. The command tells Claude
Code where to find Alkemio and which key to use.

1. Open a text editor, such as Notepad on Windows or TextEdit on a Mac, and
   paste this command into it:

   ```bash
   claude mcp add --transport http alkemio https://alkem.io/rest/mcp --header "Authorization: Bearer <your-mcp-api-key>"
   ```

2. Replace `<your-mcp-api-key>`, including the `<` and `>`, with the key you
   copied in Step 1. If your **Endpoint** address from Step 1 is different,
   replace `https://alkem.io/rest/mcp` with it as well. Keep everything else
   exactly as it is.
3. Open a terminal. On Windows, press the Windows key, type `PowerShell` and
   press Enter. On a Mac, press Command and the space bar together, type
   `Terminal` and press Enter.
4. Copy the edited command from your text editor, paste it into the terminal
   and press Enter.
5. To check that it worked, type `claude` and press Enter to start Claude
   Code, then type `/mcp` and press Enter. Alkemio should be in the list.

Afterwards, close the text editor without saving, because the command
contains your key. Claude Code also stores the key on your computer, in its
own settings file and in the terminal's list of recent commands. On a
computer that only you use, that's fine. If you share the computer,
or your organisation has rules about where passwords may be stored, check
with your IT contact before you continue.

### Claude Desktop on your own network

The [Claude Desktop](#claude-desktop) route connects through Anthropic, the
company behind Claude, over the internet. It can't reach an Alkemio address
that only works inside your organisation's own network, such as a test
version running on your own computer. In that case, you add Alkemio to a
settings file on your computer instead, together with a small helper program
that passes your key on to Alkemio.

1. Install Node.js, which the helper program needs. Download it from
   [nodejs.org](https://nodejs.org) and install it like any other program.
   Any version from 18 onwards works.
2. Open the folder where Claude Desktop keeps its settings. On Windows, press
   the Windows key and R together, type `%APPDATA%\Claude` and press Enter.
   On a Mac, open Finder, press Command, Shift and G together, type
   `~/Library/Application Support/Claude` and press Enter.
3. Open the file `claude_desktop_config.json` in that folder with a text
   editor such as Notepad or TextEdit. If the file isn't there, create a
   new text file with exactly that name.
4. Copy the text below into the file. If the file is empty, paste all of it.
   If it already contains a section starting with `"mcpServers"`, add only
   the `"alkemio"` part inside that section.

   ```json
   {
     "mcpServers": {
       "alkemio": {
         "command": "npx",
         "args": [
           "-y",
           "mcp-remote@0.14.2",
           "https://alkem.io/rest/mcp",
           "--header",
           "Authorization:${AUTH_HEADER}"
         ],
         "env": {
           "AUTH_HEADER": "Bearer <your-mcp-api-key>"
         }
       }
     }
   }
   ```

5. Replace `https://alkem.io/rest/mcp` with your **Endpoint** address from
   Step 1, and `<your-mcp-api-key>`, including the `<` and `>`, with your key.
   Leave the word `Bearer` and the space after it in place.
6. Save the file and close Claude Desktop completely, then open it again.

Alkemio now appears among Claude Desktop's tools.

If it doesn't, and you're on Windows, a Windows safety setting may be blocking
the helper program. You'll then see an error that includes
`running scripts is disabled on this system`. To allow the helper program,
open PowerShell (press the Windows key, type `PowerShell` and press Enter),
paste the command below and press Enter. If PowerShell asks you to confirm,
type `Y` and press Enter. Then restart Claude Desktop.

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

{/* Note for maintainers: the key sits under `env` rather than in `args`
because Windows can break a value containing a space when it is passed as an
argument, which shows up as a confusing sign-in failure. The helper version
(`mcp-remote@0.14.2`) is pinned on purpose, because it handles the user's key;
only raise it after checking the newer version. */}

### Other AI assistants

Other assistants can also connect to Alkemio, as long as they support MCP
over the internet. In their settings, this is sometimes called
"Streamable HTTP".

1. In your assistant's settings, look for the option to add an MCP server or
   a connector.
2. As the address, enter the **Endpoint** address from Step 1.
3. Add a header with the name `Authorization`. As its value, type the word
   `Bearer`, a space, and then your key.

If your assistant has a field called "API key" instead of a place to add
headers, try pasting your key there. Many assistants then send the key in a
form that Alkemio also accepts.

## Switching a key off

If you no longer need a key, or you think someone else may have seen it,
switch it off immediately:

1. Click your profile picture, choose **My Account** and open the
   **Security** tab.
2. Under **MCP API Keys**, find the key by its name and click **Revoke**.
3. Confirm by clicking **Revoke key**.

The key stops working immediately, also in any assistant that is still
connected with it. If you still want to use your assistant with Alkemio,
create a new key and repeat Step 2.
