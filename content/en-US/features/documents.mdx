# Documents

Documents let your community work together on text documents, spreadsheets and presentations, directly inside a Space. Several members can edit the same document at the same time and see each other's changes live.

Documents are an extra feature that is turned on per Space. If it isn't turned on, you'll see the message *Office documents are not enabled for this space*.

## Adding a Document

There are two ways to add Documents to a Post. In both cases, everyone in the Space can edit them:

- **One Document in the Post**: when creating a Post, choose **Document** as additional content. The Post then has one document that everyone works in.
- **Several Documents added by members**: when creating a Post, choose **Documents** as the type of contribution. Members can then each add a document with **Add document**.

You can then start a new document by entering a **Document title** and choosing the **Document type** (Text Document, Spreadsheet or Presentation), or use an existing file: **drag & drop a file, or click to upload** (.docx, .xlsx, .pptx or .pdf). Word, Excel and PowerPoint files become editable; a PDF can only be viewed. To put a newer version in place later, use **Replace file**.

Want to share a file exactly as it is, such as a finished report? Then choose **Links & Files** as the type of contribution instead, and add the file yourself under **Pre-populate collection**. Others can open or download it, but not edit it.

## Working in a Document

Click **Open Document** to open it (for a PDF, click **View**). With edit rights it opens in edit mode, otherwise in view-only mode. Changes are saved automatically; a save indicator at the bottom shows whether your changes are saved and who else has the document open. If the editor doesn't load, try again in a few minutes.

To **rename** a document, change the title in its settings; the name stays in sync with the Post title. To **delete** it, choose **Delete document** and confirm. Deletion is permanent.

## Who can add and edit Documents

All members of a Space can view and open documents. Whether members can also add and edit them depends on the Space settings: Space admins control this via **Settings > Allowed Actions > Create Posts**. When this is turned off, only admins can add or edit documents.

## Tips

- Use **text documents** for meeting notes, project descriptions, or any written content the team works on together.
- Use **spreadsheets** for tracking tasks, budgets, timelines, or structured data.
- Use **presentations** for proposals, overviews, or visual summaries to share with the community.
